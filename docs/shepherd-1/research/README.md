# Research notes behind the Shepherd-1 design

These files are raw research sweeps run on 2026-11-01 by delegated research
agents while the Shepherd-1 diagram was being built. They are working notes,
not reviewed documentation: numbers come from search-engine excerpts of the
cited pages (direct fetches of most vendor sites were blocked from the build
environment), and anything the agent could not verify is tagged `n/p`,
`[UNVERIFIED]`, `(?)` or `[mem]`. Re-verify against the cited datasheet before
quoting a figure in a document that leaves the team.

| File | Scope |
| --- | --- |
| `buses.md` | COTS CubeSat / ESPA / ESPA-Grande / 1–3 t buses, launch interfaces, which buses can host 1 / 5 / 20 kW payloads |
| `comms-references-concerns.md` | Optical crosslink terminals, RF TT&C, relay services, reference RPO spacecraft, general design concerns (cold welding, atomic oxygen, MMOD, radiation, charging, HDRMs, lubricants, plume impingement, Laser Clearinghouse) |
| `propulsion-gnc.md` | Electric propulsion catalogue, delta-v arithmetic, wheels / star trackers / fine steering mirrors |
| `laser-optics-sensors.md` | Flown space lasers, commercial high-energy short-pulse lasers, SiC optics, contamination control, debris detection sensors, L'ADROIT / ORION parameters |
